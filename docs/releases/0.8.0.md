# Scoped 0.8.0

Release date: October 12, 2026.

## Changes since 0.7.0

- Add private posting notes, including saving a posting with notes. Notes survive collection refresh and local library changes.
- Track applications from other sources with custom Applied entries, application dates, organization, location and notes.
- Mark positions as not relevant with checkboxes, row clicks or mouse/pen range dragging. Marks save in batches; hiding and ordering apply after finishing marking.
- Include notes, custom applications and relevance marks in full backup/restore.
- Collapse desktop filters to give more room to results. Each collection view remembers its own sidebar preference; narrow layouts retain the Filters dialog.

## Install or update

Release archives and SHA-256 checksums are in `release/0.8.0/`. The Firefox ZIP is unsigned and requires Mozilla signing for permanent installation. The Chrome ZIP can be extracted and loaded unpacked.

Back up your data through **Backup & restore** before changing installations. Reload an existing development installation after rebuilding, then reopen its extension pages. See [distribution instructions](../distribution.md).
